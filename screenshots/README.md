# Screenshots

## Naming
Use `section-topic-what-it-shows.png`, all lowercase, no spaces.
Examples: `hardening-ssh-before-check.png`, `network-wireshark-tcp-handshake.png`

## Before you add a screenshot, remove or blur
- Real home IP addresses and your router address
- Public IP addresses
- MAC addresses
- Real usernames, email addresses and hostnames
- Passwords, tokens, API keys and SSH keys (even partly visible)
- Wi-Fi names
- Flags and answers from CTF or wargame platforms

Lab addresses like `192.168.56.x` are fine to show.

## Tips
- Crop to the relevant part. Do not post full desktop screenshots.
- Keep each image under about 500 KB (PNG for text, JPG for photos).
- Write helpful alt text: `![UFW status showing port 22 allowed](...)`.
- Put unedited originals in `screenshots/raw/` (it is in `.gitignore`).
