# 12-Week Learning Roadmap

A steady plan: a few hours per week is enough. Tick the boxes as you go and write a note for each item.

| Weeks | Focus | Deliverable (a note in this repo) |
|-------|-------|-----------------------------------|
| 1-2 | Lab setup and Linux basics | VirtualBox, Kali, Ubuntu Server, network design, permissions, commands |
| 3-4 | Networking | Subnetting practice, ports and protocols, first Wireshark captures |
| 5-6 | Hardening | SSH keys, UFW firewall, automatic updates |
| 7-8 | Log analysis | Reading auth logs, detecting brute force, fail2ban |
| 9-10 | Web security basics | DVWA modules with the matching fixes |
| 11-12 | Practice and review | OverTheWire Bandit, TryHackMe rooms, clean up the repo |

## Weekly checklist
- [ ] Learn one concept and read about it from at least two sources
- [ ] Try it in the lab
- [ ] Write the note (use [NOTE-TEMPLATE](NOTE-TEMPLATE.md))
- [ ] Run `secret_scanner.py` and commit
- [ ] Write the defensive takeaway: how would I prevent and detect this?

## Free resources
- **OverTheWire Bandit:** learn the Linux command line through a game
- **TryHackMe:** guided rooms (check which learning paths are current)
- **Linux Journey:** beginner Linux lessons
- **Professor Messer:** free videos covering CompTIA Network+ and Security+ topics
- **OWASP Top 10:** the standard list of web application risks
- **CIS Benchmarks:** detailed hardening guides for operating systems
- **NIST Cybersecurity Framework:** how organisations organise security work

## Possible certifications (optional)
Look up the current details before you decide: ISC2 Certified in Cybersecurity (CC), CompTIA Security+, CompTIA Network+, Google Cybersecurity Certificate.
