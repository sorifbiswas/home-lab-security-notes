# TryHackMe: Room Log

**Goal:** Learn through guided, legal, browser-based labs, and write down what I learned from each room.
**Status:** Draft

---

## How I use the platform
- I start from a **learning path** and check the platform for the current path names (for example beginner and SOC-analyst style paths), because they change.
- I try each task myself before using hints.
- Many rooms use their own virtual machines. That is fine: they are built for practice.

## Rules for my write-ups
- **No flags, answers or passwords.** Most platforms ask that solutions are not published, and posting answers also defeats the learning.
- Write **concepts, commands I learned, and mistakes**, not a walkthrough.
- Always add the **defensive takeaway**: how would someone prevent or detect this?
